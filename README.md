Программный продукт для автоматизированного анализа данных с использованием ИИ-агента. Проект выполнен в рамках задания "Анализ данных с помощью LLM".

---

## 🎯 Описание проекта

Это веб-приложение на базе **Streamlit**, которое превращает обычный CSV-файл в интерактивный объект для исследования. Сердцем системы является **ИИ-агент**, построенный на базе фреймворка **LangChain**.

### Ключевые особенности:
* **Агентная логика**: LLM не просто анализирует текст, она **пишет и исполняет реальный Python-код** в изолированной среде для получения точных расчетов.
* **Инструментарий аналитика**: Использование библиотеки `pandas` для фильтрации, группировки и статистического анализа.
* **Интерактивный UI**: Полноценный чат-интерфейс с сохранением истории сообщений, боковой панелью и кнопками быстрого анализа.
* **Защита от Prompt Injection**: В систему встроен жесткий системный фильтр. Если пользователь попытается увести ИИ от темы, агент откажется, сохраняя роль аналитика.

## 🚀 Инструкция по установке

### 1. Клонирование репозитория

```bash
git clone [https://github.com/Loliimilk/Mini-LLM-analytics](https://github.com/STasich-CODe/AI-Data-Analyst-Agent-LSY/edit/main/README.md)
cd Mini-LLM-analytics
```
### 2. Подготовка окружения
Убедитесь, что у вас установлен Python 3.13. Склонируйте репозиторий и создайте виртуальное окружение:

```bash
python -m venv venv
venv\Scripts\activate  # Для Windows
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```
### 4. Конфигурация
Создайте в корневой папке файл .env и добавьте ваши ключи:
```
OPENAI_API_KEY="ваш_ключ_proxyapi"
OPENAI_BASE_URL="[https://api.proxyapi.ru/openai/v1](https://api.proxyapi.ru/openai/v1)"
```
### 5. Запуск
```bash
streamlit run app.py
```
