# 📊 AI Data Analyst Agent (LLM-Аналитик)

Программный продукт для автоматизированного анализа данных с использованием ИИ-агента. Проект выполнен в рамках учебного задания по курсу "Анализ данных с помощью LLM".

## 🎯 Описание проекта
Это веб-приложение на базе **Streamlit**, которое превращает обычный CSV-файл в интерактивный объект для исследования. Сердцем системы является **ИИ-агент**, построенный на базе фреймворка **LangChain**.

### Ключевые особенности (Почему это 5 баллов):
- **Агентная логика**: LLM не просто галлюцинирует на основе текста, она **пишет и исполняет реальный Python-код** в изолированной среде для получения точных расчетов из вашего датасета.
- **Инструментарий аналитика**: Агент использует библиотеку `pandas` для фильтрации, группировки и статистического анализа.
- **Интерактивный UI**: Полноценный чат-интерфейс с сохранением истории сообщений, боковой панелью управления и кнопками быстрого анализа.
- **Защита от Prompt Injection**: В систему встроен жесткий системный фильтр. Если пользователь попытается увести ИИ от темы (попросит написать стих или сторонний код), агент откажется, сохраняя роль дата-аналитика.

## 🛠 Стек технологий
- **Backend**: Python 3.13, LangChain
- **Frontend**: Streamlit
- **LLM**: OpenAI GPT-4o-mini (интеграция через ProxyAPI)
- **Data Science**: Pandas, Tabulate
